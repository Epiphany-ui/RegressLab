# 算法设计：历史群体风险与预算约束选样

2026-10-23。HGC 为待验证候选。公式为本次提出的具体实验设计；借鉴已有群体发现、收缩估计和子模覆盖思想，**未确认学术首创，也未验证效果**。

## 1. 时间轴和信息边界

至少使用四个真实版本：`f0 → f1 → f2 → f3`。f2 是当前参考版本，f3 是未见目标版本。已知 f0、f1、f2 的历史预测；不能用 f3 的预测、logits、梯度、参数差或错误标签选样。算法甚至不需要加载 f3。离线计分器之后会全量运行 f3，这笔费用属于研究取得金标准的成本，不能假装部署时已经省下。

给定发现数据 D 和正确标签 y，候选池：`P = {i in D : f2(x_i)=y_i}`。选择 `S⊆P, |S|≤B`。目标集合：`R*={i in P : f3(x_i)≠y_i}`。主目标是提高 `|S∩R*|/|R*|`。本研究在“当前正确的题”中寻找下一次可能做错的题，不研究如何修复当前已经错误的题。

历史转移 t∈{0,1}，定义 `E_it=1[f_t(x_i)=y_i]`，`H_it=1[f_t(x_i)=y_i and f_(t+1)(x_i)≠y_i]`。所有历史样本均可用于估计群体风险，但最终套件只从 P 选。

**陷阱：**在 P 内，最近转移 f1→f2 的负向翻转恒为零。因此有效历史单点基线是“任意过去转移发生过负向翻转”，不是只看最近一次。四版设计保留 f0→f1 出错、到 f2 又修好的样本；只有三版时不能假装拥有这类历史。另一个可研究的协议是固定 f0 作全部对照，但它回答长期兼容性问题，不能与本协议混在同一指标中。

## 2. 两类群体必须区分

**风险群体**指历史条件负向翻转率较高的群体；其总体净准确率可以仍然提高。**净下降群体**指同组 `b-c>0`，其中 b 为旧对新错、c 为旧错新对。HGC 服务于个体负向翻转检出，因此用前者构建风险；诊断报告并列后者，不能把二者混称为“已确认退化”。

现有净下降枚举器保留为对照。第一轮方法候选共用固定特征：正确意图标签、文本长度分箱、否定词标记、数字标记、问句标记；长度边界在开发数据固定。中英否定词表分别版本化。它们只是可解释表面特征，不能覆盖全部语义。先不使用自由 LLM 生成特征，避免成本、不可复现和结果驱动构造条件。

两种可实现的发现路径：

1. **简单强对照：**枚举单条件和两条件合取，在 D 上计算历史风险与支持度。
2. **已有方法适配：**SliceLine/DivExplorer 提供可解释候选；用负向翻转的二值目标或成对损失变化适配，并清楚标记“适配版”。需要条件负向翻转率时，单次转移须在该旧版正确的子池上统计，不能把所有旧错误样本作为无风险负例稀释分母。

Domino/Edisa/ChangeLists 式混合模型用作不同表示家族的诊断比较，不要求在同一谓词空间里比速度。表达能力不同须分别讨论。

## 3. HGC 的风险权重（具体初始设定）

对候选群体 g、每次历史转移 t，`e_gt=Σ(i∈g∩D) E_it`，`b_gt=Σ(i∈g∩D) H_it`，`p0_t=ΣH_it/ΣE_it`。若全局旧正确样本为零，该次转移不参与风险估计并记原因。

采用向全局率收缩的风险：

`p_gt = (b_gt + m*p0_t)/(e_gt+m)`，初值 `m=30`。

它降低小群体一次偶然错误的影响，但不是 p 值或置信下界，也不是已校准的未来概率。m 是待开发集选择的超参数。

令 `u_gt = max(0,p_gt-p0_t)`。若 `e_gt<10`，本次 u 记为0并保留低支持标记；阈值只是一项设计选择，不提供统计功效保证。定义

`q_g = mean_t 1[u_gt>0]`

`w_g = mean_t(u_gt) * (1+q_g)/2`。

这给多次历史中重复呈现风险的群体更多权重。这里的重复指**群体风险**：单条样本不可能在两个相邻转移都负向翻转，因为第一次翻转后已经错误。**两次时间点高度相关，q 不能解释为独立重复实验或未来风险保证。**每一历史时点都必须在目标 f3 之前。

排序后以 D 成员 Jaccard≥0.9去重，最多保留30组，最后按谓词字节序打破同分。只对在 P 中至少含一个样本的组建立选择目标。去重不消除全部重叠，重叠群体可能重复表达同一风险，需在消融与案例中检查。若所有 w=0，算法显式退化为代表性选择，不伪造风险分组。

**C/A 的角色：**以上权重只由 D 形成。C/A仅服务可选的独立诊断扩展；若要声称统计确认，按实验协议的成对检验与校正执行。风险组可以作为探索性选样特征，但不能被报告为已确认净退化。主选样策略不根据 C 的结果开关或调权重。高翻转风险与净准确率下降是不同目标，不设含义不明的“只用已确认风险组”必做消融。

## 4. 选样目标

把群体权重归一化为 `wbar_g=w_g/Σw_g`。固定饱和数 k=3，定义

`G(S)=Σ_g wbar_g * min(1, |S∩g|/k)`。

含义：高风险群体获得较高优先级，同一群体选到三条后不再单凭该组获益。k=1相当于一次覆盖，k=3并非天然最优，由消融检验。

代表性项采用固定锚点的 facility-location 形式：

`F(S)= (1/|U|) * Σ_(u∈U) max_(i∈S) K(u,i)`，空集的 max 为0。

U 从同一个候选池 P 以类别分层、固定 hash 选取至多256个锚点。K 是 D/P 内拟合的非负字符 TF-IDF 余弦相似度，范围[0,1]。没有向量的文本相似度记0；不读取 C/A 或 f3 表示。使用 TF-IDF 只是低成本初始表示，不能宣称语义相似。TF-IDF 与小型固定文本编码器的对照属于表示敏感性实验；编码器下载和嵌入时间计入建库。

总目标：`J(S)=λG(S)+(1-λ)F(S)`，λ初值0.5。若无风险组，直接令 J=F，不做除零；这次运行记录 fallback。非负固定权重、固定 U/K、固定 k/λ下，J 是归一化非负单调子模函数：群体计数上的凹饱和函数具有边际递减，facility-location 的 max 相似度也具有边际递减，非负和保持该性质。

这是对已知数学结构的实例化，**不是提出新子模理论**。在纯数量约束下，每轮选最大边际收益的标准贪心有经典 `1-1/e` 近似界；界限只针对 J 的最优值，不针对未来 Recall、真实风险或最优回归套件。[经典原论文](https://www.cs.cmu.edu/~aarti/Class/10704_Fall16/submod-max.pdf)

不得加入负的成对冗余惩罚、最小群体收益或预算动态变化后继续直接引用上述保证。非均匀成本的“边际收益/成本”也不自动继承此界。本轮主实验使用数量预算，真实时间单独评价。

## 5. 求解与复杂度

```text
读取 D 的历史结果；冻结 P、候选组、w、向量器、U、K
S = 空集；每组已选计数=0；每个锚点当前覆盖相似度=0
重复至 min(B,|P|)：
    对每个未选 i 计算增加 i 后的 ΔG、ΔF、ΔJ
    选 ΔJ 最大者；同分按 sample_id 字节序
    更新该例所在组计数及锚点最大相似度
冻结有序 ID、目标配置、全部依赖 hash；输出不含 f3 字段
```

设 n=|P|、a=|U|、d为每例所属组数，简单实现约 `O(B*n*(a+d))`；存锚点相似度矩阵 `O(a*n)`，不建立 n×n全矩阵。群体搜索和向量计算另行计时。先实现明确的精确贪心，再按实测决定是否加 lazy greedy；有限精度下需核对选择序列。所有预算使用同一个 J，贪心序列可取前缀，不能因预算变化悄悄重调目标。

## 6. 消融与改进边界

- λ=0：只有代表性；λ=1：只有群体风险覆盖。
- w全设相等：测试风险权重价值；k=1：测试多例饱和覆盖价值。
- 单次历史 vs全部历史：测试重复历史是否有用；历史数量不足单列，不能补造。
- 相同候选组下随机选组内代表、按历史风险逐例 Top-B、HGC：分辨群体信息和求解目标的作用。
- 全相同候选池、预算和信息；Legacy-v1 单列，不能悄悄改成 HGC 后沿用旧名字。

第一轮只开发 λ∈{0.25,0.5,0.75}、m∈{10,30}，k默认3、另用1作机制消融。最多6个核心配置；特征与候选数先固定，不与所有消融做笛卡尔乘积。开发集确定后冻结，最终结果不再选参数。若收益不好，不无限堆特征、融合模型和重复试验。

## 7. 为什么可能失败

群体在历史上风险高，不等于未来仍高；当前正确过滤会改变群体构成；表面特征无法捕获深层语义；固定锚点可能偏向大类；相互重叠的组可产生虚假多样性；新更新可能修复历史问题却在其他地方引入错误。保留这些反例并按更新家族报告，是研究的一部分。
