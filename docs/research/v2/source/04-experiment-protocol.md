# 实验协议与可行性门槛

2026-10-23。下述数值是拟定的开发/冻结规则，不是实测结果。正式实验前将配置、代码和数据清单锁定，修改保留版本。

## 1. 两个数据集，不把翻译当独立证据

主数据 MASSIVE 1.1 的 zh-CN 意图分类；辅助 MASSIVE en-US 用于语言敏感性，不作为独立语料重复。独立外部数据建议 CLINC150 的 in-scope 子集，仅做150类闭集意图分类，明确排除 OOS 预测。本项目不增加槽位识别任务。[MASSIVE 官方](https://github.com/alexa/massive)、[CLINC150 官方](https://github.com/clinc/oos-eval)

MASSIVE 1.0 为51语言，1.1加入 Catalan 后为52；有60意图、55槽位类型。旧版泛称51语言应注明版本。id 可对应同一个源 utterance，scenario 是领域，不是已知的独立模板 ID。多语言联合时，同源 id 的所有语言必须在同一组件/分区。重复与规范化文本相同项建立组件，同组件不跨训练、开发与测试；冲突标签单列清理，不静默改 gold。[官方版本及字段](https://github.com/alexa/massive/blob/main/README.md)

金标准有两层：意图正确答案由数据集提供；未来负向翻转标签由相同文本的参考/目标预测与 gold 比较得到。数据集没有穷尽所有真实退化群体的标注，因此自然数据不能直接计算“发现了全部真实群体中的多少”。模拟实验才有人工指定的潜在风险群体真值。

许可证、原始文件 hash、下载版本、实际清理前后计数、同源组件数均写入 manifest。训练有可能接触公开基准的预训练文本，这是无法从本实验排除的限制，不能宣称完全无预训练污染。

## 2. 样本轴与模型版本轴分开隔离

官方 TRAIN 只训练任务模型；DEV 按组件分成模型开发与选样算法开发两部分。所有方法参数、特征边界、预算主指标和比较器在开发阶段决定。开发结果不能使用正式 TEST 的 f3 错误来选参数。

官方 TEST 按组件固定分成 D/C/A，本研究初定80%/10%/10%，记录实现与类别支持度。D用于主研究的历史群体建模和套件候选；C/A保留给可选诊断扩展。此比例取代旧应用方案50%/25%/25%，因为选样是当前核心；冻结前用开发集检验数量可行性，不能看正式目标后调整。以真实源文件为准，MASSIVE每语言测试约2974行，C/A各约300行，细意图支持很少，**不把细类显著性确认列为核心必达结果**。

**选样评价另有版本隔离：**f0、f1、f2在D的预测可见；f3在D的完整预测由评测器封存。先生成全部方法、全部预算的套件，再解封 f3 计分。套件的未来召回分母是同一个 P⊆D 的真实负向翻转数，不能把不在套件候选池的 A 错误放进分母。A用于验证群体跨样本表现，回答另一个问题。

同一测试文本的历史记录用于未来选样是本任务的允许信息，不属于泄漏；目标版本结果参与任何选择则属于泄漏。若研究者已查看过某批真实目标结果并据此设计方法，该批数据只能视为开发/探索，不能改名后称全新保留集。之前合成 Demo 的 A 不等于真实 MASSIVE 的 A 已被污染；需核对实际访问记录。

## 3. 模型更新怎样生成

### 3.1 低成本主比较：CPU分类器

先用固定字符/词 TF-IDF＋逻辑回归和一个小型 MLP/SGD 分类器完成方法筛选及较多真实更新。训练向量器仅使用 TRAIN，标签集合固定；同链各版本使用相同的推理流程。变化来自实际重训，不修改预测文件制造退化。

三类预先固定的更新家族：

- 数据增长：按标签分层嵌套 TRAIN 子集，f0/f1/f2/f3分别使用40%/60%/80%/100%。
- 训练混合变化：使用 TRAIN 中预先选择的领域/意图采样权重逐步变化，同时各阶段保留全部类别。选定领域由固定种子产生，不能观察测试退化后挑领域。
- 训练配置变化：在同一特征/标签下改变预登记的正则化或优化预算，并实际重新拟合。配置是更新因素，不据测试分数挑最好/最坏版本。

每条链独立记录 TRAIN抽样或优化随机性。对 `LogisticRegression(solver='lbfgs')` 只换 random_state 通常不改变训练过程，不能因此声称三次独立实验；应真实改变 TRAIN抽样实现，或采用有明确随机机制的优化器。[scikit-learn说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)

先做每家族3条链，再根据测得成本增加廉价链；开发链和最终链种子预先分开。跨家族留出一类作为迁移检验，不把所有家族都反复用于参数选择。重复数据、相同架构和同一初始权重使链仍然相关，不能将所有链、检查点和文本行混成独立样本。

### 3.2 神经模型迁移验证

以现有计划的 Qwen3-0.6B 加 LoRA 为候选，在固定 TRAIN 上真实训练，并保存四个预先指定检查点。先做 DEV短程实验，记录峰值显存、每步耗时、推理吞吐、标签合法率和复跑稳定性；6GB能否支持具体配方尚未实测。[模型卡](https://huggingface.co/Qwen/Qwen3-0.6B)、[LoRA文档](https://huggingface.co/docs/peft/package_reference/lora)

固定0.6B一种规模，不做大规模模型大小竞赛；目标最多3条独立训练实现，若预算不够至少如实报告一条迁移案例，结论限定为案例。四个相关检查点只是一条链，不是四个独立更新。版本顺序、推理后端、标签映射、解码设置一致。训练输出不稳定或非法输出应单列执行问题，不能静默删行优化指标。

是否采用生成式标签或分类头，在预实验后固定。若生成标签，首个token概率不是完整意图类别概率；共享前缀标签尤其不能据此实现60类DeepGini。参考分数基线须采用定义明确的完整标签似然/分类头概率并计入获取成本；无法提供合法可比分数时，仅运行标签访问层，不伪装完成分数基线。

不需要 DeepSeek API。若GPU实验失败，保留CPU研究但不能声称已经证明在大语言模型上有效，也不能偷偷改提示词代替权重更新。

## 4. 分访问条件的强基线

### 4.1 主表：目标版本推理前选样

所有方法共用 P、B、历史版本、正确标签和固定特征。不允许 f3 的全池推理。

| ID | 方法 | 精确定义/用途 |
|---|---|---|
| Random | 无放回均匀随机 | 20种选样种子；估计最基本参照 |
| Stratified | gold意图比例分层 | 最大余数分配；预算小于类数允许零名额 |
| PastFlip | 任意历史负向翻转优先 | 按历史次数/有效机会数排序，同分随机；最近一次在P恒零，不能拿它假装强对照 |
| Ref-Uncertainty | 当前参考版本不确定性 | 分别跑低最大概率、低margin、entropy、DeepGini；使用f2分数，不是f3。开发阶段选一个主不确定性比较器，其余完整报告 |
| KCenter | 最远点多样性 | 与HGC同文本表示，记录随机起点20次 |
| Facility | 只有代表性项 | 与HGC相同U、K，λ=0；最必要机制基线 |
| Risk-Top | 历史风险Top-B | score(i)=Σg wbar_g·1[i∈g]；按分数降序、ID升序，零分自然补足；是群体项首步边际收益的等比例排序，不做互补更新 |
| Risk-LR | 简单历史风险预测器 | 只在开发历史中旧版正确行训练翻转二分类；特征为意图one-hot、同一表面特征、此前翻转次数/机会数；有合法参考分数时另开分数版。L2、C=1、class_weight=balanced，训练器和特征映射冻结；正式输入只使用f2及更早信息 |
| Behavior-Anchor | 历史行为聚类 | 历史正确性向量/参考置信度聚类选代表；注明是AnchorPoints/tinyBenchmarks启发的适配版，非完整IRT复现 |
| Legacy-adapt | 原工程启发式的任务适配 | 保留精确元组(gain,H,diversity)；组义务为本次D风险候选，权重2；gold类别义务权重1；gain是新覆盖权重；H为任意历史翻转标记；diversity为到已选集最小TF-IDF距离，首轮1；ID打破同分。替代了原C确认组/最近翻转，明确不叫原样复现 |
| HGC | 拟议方法 | 群体历史风险＋饱和覆盖＋代表性，见算法文档 |

Risk-LR必须说明开发与正式的迁移条件；DEV样本被模型训练/选择过会低估风险，需单列该限制。标签访问主表与需要 f2分数的参考访问层分别标识；方法本来不使用某信息不等于刻意限制其他基线。

### 4.2 最接近但访问更强的方法

**GBV-PD/Grad-PD：**CPU小分类器上优先实现一阶完整梯度方向性参考，再与官方GBV-PD降维/排序规范核对。GBV-PD可读取f3权重差，不进行f3全池推理，属于白盒层。所有梯度缓存、PCA和参数提取计入成本。LoRA参数梯度版本是适配，不能声称复现了原论文未做的文本实验。[GBV-PD](https://arxiv.org/html/2606.28037v2)

**RiskBlend、MetaSel、跨版置信度/KL、CASPER：**单列增强访问表。若方法需要全池f3概率，费用必须完整计算；若只探测少量f3样本，探测数也算入总预算。RiskBlend多分类适配与MetaSel的历史替代版本均另命名，不能直接冒充原方法。CASPER完整依赖LLM日志、多目标搜索与少量目标探测，首先核对可复现包和任务适配，再决定原样复现还是明示简化。

若HGC在更少访问下检出接近这些方法，可讨论访问/费用折中；不能据此宣称无条件超过它们。若没有实现最近基线，应明确缺项，不能用十个弱基线数量代替。

## 5. 最小核心与群体发现扩展

**核心必须完成：**一个固定的可解释谓词生成器，HGC与第4.1节选择基线（分数不可得时明确访问层），CPU开发两更新家族＋一留出家族，独立外部意图数据验证，CPU方向梯度强参考，成本与主要机制消融。神经模型迁移按资源门槛进入；MASSIVE en-US、完整IRT、多种群体发现器竞赛和正式群体确认都不与这些核心并列为毕业前置条件。先完成最小核心，再增加下面扩展。

群体扩展优先比较元数据/单条件基线、二条件枚举、SliceLine适配、DivExplorer适配；其中至少一项可安装实现用于核查本研究固定谓词方法是否过弱。不同方法先在D冻结候选，每种最多同样的K=10个不重复组，再在C执行相同审查。不能给某方法100个机会而给另一种10个。

ChangeLists/paired-Domino为直接成对发现参照；Edisa/DEIM提供NLP嵌入方法；AutoSlicer也已做跨版差异。至少选一种语义/嵌入家族作为扩展，或者明确本研究只比较谓词族、限制外推。此部分不要求把所有十种方法复现完再开始主实验。

指标：C上实际效应分布、确认产出数、组间重叠、独特受影响样本覆盖、运行时间、条件长度；自然数据的这些指标不是“真实群体召回率”。HGC选样用D软风险；C只作审查，不能边看C边改特征。

## 6. 指标与统计

主预算 B=100；辅助B∈{20,50,200}，n不足则按实际n报告并避免重复预算计成多个独立实验。每种方法输出同一目标的完整曲线，不能事后只挑赢的预算。

- `Recall@B = |S∩R*|/|R*|`；R*为空时记NA并保留该链，另报“无负向翻转”。
- `Precision@B = |S∩R*|/|S|`，并报具体检出数。
- Enrichment为Precision除以P中的全池翻转率；全池率为0时NA。
- 单列历史未见错误的Recall、修复后复发错误的Recall及各自分母。不能用检出同一历史错误的收益声称发现了新模式。
- 有完整排序时可报排序曲线/AUC；采用何种预算坐标与归一化须固定。经典APFD的一“fault”在本实验指样本翻转事件，不是已定位的独立软件缺陷。
- 对人为选样的集合，直接平均其准确率通常有选择偏差，不能当作全数据无偏准确率。主研究不承诺准确率估计。

随机种子先在每条模型链内汇总，不当作新的更新样本。按数据集、训练家族、模型、链展示配对差值；不能把数千文本行当作跨模型有效性的样本量。小样本优先报告效应量和完整结果；只有足够的独立训练实现且相关性处理有根据时才给推断性区间/检验。固定模型下的组件bootstrap只解释这个模型和样本池的抽样不确定性，不解释所有未来模型。

主比较器在开发结果中从非HGC方法选定并冻结，不在正式测试中挑一个弱者。多方法统计检验以预先声明的家族做Holm校正；辅助实验为探索性，不能用许多未经校正的p值拼结论。

**“更好”的拟定实用门槛：**主预算Recall比冻结强基线高至少0.05，并有足以支持该结论的跨更新证据，同时报告全部费用；这不是预期结果或必达毕业线。

**“至少持平”的拟定门槛：**预先把可容忍损失设为Recall绝对0.03；配对差 `d=HGC−baseline` 的有效单侧95%下界须高于−0.03，并且总成本至少下降20%或有明确更弱访问要求。此数值需导师在看正式结果之前认可；样本量不足导致区间太宽时应写“证据不足”，不能改成“不显著所以持平”。标注“观察到的成本/效果折中”也比虚假的非劣结论更好。

## 7. 群体确认：不要把净下降与高翻转混检

对冻结的净下降候选，在C选独立组件代表，按b/c执行单侧精确McNemar，Holm控制本次冻结候选家族；显示效应大小。该检验测试净退化零假设，不直接检验下降超过5个百分点。风险率高于全局是另一种选择目标，本轮不为其硬套McNemar“已确认”标签。[SciPy精确二项检验](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html)、[Holm实现](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)

全方法候选并集若一同声称确认，按该并集确定校正家族；对重复谓词规范化。一次C未通过后不再调门槛重跑同一C。若探索多训练链，每链0.05不是全项目或持续升级的终身0.05保证。

若开展确认扩展，功效预实验先做：n=40、b=2、c=0，即观察下降5个百分点，单侧精确p=.25。20项Holm首项门槛为.0025，b=9、c=0时原始p约.00195，但对应22.5个百分点下降。**支持度40不是检测5个百分点下降的充分证据。**小类无足够功效就如实描述，不降低门槛制造确认。

## 8. 可控模拟与真实实验分开

模拟构造有已知潜在群体、不同历史复发性的成对正误结果。包括：所有局部均无净变化；新旧共同低准确率；净零但双向翻转；重复风险；目标新风险；少数群体；重叠群体；错误表面特征；历史风险被修复/反转。每种设置先固定数据规模、支持、概率、重复次数，再执行完整发现和审查流程。

主选择研究先运行四类小模拟：重复风险、目标新风险、历史风险修复/反转、重叠群体，以解释选样机制。只有声称群体统计控制时再做1000次完整发现/确认模拟；空假设必须保证每个候选局部的b/c交换对称，不是只让全局b=c，报告FWER的Monte Carlo区间。已知群体评价先固定一对一Jaccard匹配阈值，不能让许多重叠返回组同时匹配一个真组抬高召回。模拟不等于真实权重更新证据。

## 9. 总成本与摊销

分别记录：数据清理/嵌入、历史模型全池推理、训练、风险建模、选样、梯度/PCA缓存、f3探测、B条目标推理、研究用f3全量金标准。

**主研究只评价一次未见相邻更新：**已有完整历史条件下，成本为 `T_select + T_probe + T_infer(B)`；从零起步还须加 `T_build`。分别与该次全量 `T_infer(n)` 比较，历史缓存复用和从零建库两本账都报告。

**不默认支持低成本无限滚动：**若f3只跑B条，则下一次f3→f4无法免费知道完整f3正确池及f2→f3群体风险。若每次刷新全池历史，滚动成本必须加 `Σ_j T_refresh,j`，可能抵消全部节约。冻结参考版本复用套件或稀疏历史是不同协议，本轮不声称已解决，也不计算无依据的重复回本次数。CPU分类推理极快时，选样本身可能更贵，应明确研究意义可能只在昂贵目标推理或本来就有历史全评记录时成立。

主预算为样本数，不自动等于token、秒数或费用相等；额外给实测时间曲线，不能仅由B/n推导API节省金额。API不参与主实验，不估算未经核查的DeepSeek价格。

## 10. 小实验的Go/No-go

| 关卡 | 通过条件 | 不通过时的处理 |
|---|---|---|
