# RegressLab：研究方向调整方案 v2

日期：2026-10-23。状态：文献核查后的研究设计，尚无算法优劣实验结果。

## 这次改变什么

建议论文题目：**《基于历史群体风险的文本分类模型回归测试样本选择方法研究》**。

英文题目：**Research on Regression Test Sample Selection Method for Text Classification Model Based on Historical Population Risk**。

按**方法研究与实验验证**组织论文。学校正式的论文类型名称仍以学院和导师登记为准。界面系统 RegressLab 保留，承担实验复现、案例分析和结果展示；需求分析、数据库和页面开发不再构成论文主线。

核心问题是：**仅利用已部署版本及更早版本的评测记录，能否在执行下一版模型前选出一个小测试集，比合理的已知方法找到更多新引入的错误，同时控制建库和选择成本？**

这不是“已有方案已被证明创新”。文献已经覆盖成对局部变化、跨版本风险排序、历史模型选点、覆盖与多样性。拟研究的具体切口是少量历史更新、无需目标版本参数或全池预测、意图分类、当前版本正确样本池中的未来负向翻转。该组合的研究价值需由最近工作比较和实验决定，不能以关键词组合代替创新证明。

## 与旧版文档的关系

本目录取代 `model-regression-design-v1.3` 中的**题目、应用开发优先级、算法默认方案和实验验收口径**。旧版技术合同可以作为已有实现参考，不能再把旧版“完整应用开发验收”当作本研究的主要目标。旧文件留档以免丢失已有工作，本轮没有修改或推送 GitHub 仓库。

原 `1000×覆盖 + 10×历史错误 + 多样性` 启发式降为 **Legacy-v1 基线**，不是研究方案的默认胜者。新增方法暂名 **HGC（Historical Group Coverage，历史群体覆盖）**；这是实验用名，不代表首创算法。

## 三条底线

- 不承诺新方法一定优于基线；“至少持平”必须按预先给定的非劣界与成本条件检验，不能把“不显著”当作持平。
- 不用目标版本的预测、参数、梯度或最终结果调选样策略；离线全量预测只由评测器解封计分。
- 如果小实验不支持群体风险的增益，收敛为有明确边界、可复现的比较研究，并据实修改题目与结论，不反复试到赢为止。
