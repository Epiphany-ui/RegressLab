# 研究定位、问题与预期贡献

2026-10-23 · 研究方案，非实验结果。

## 1. 最终建议题目及定位

**《基于历史群体风险的文本分类模型回归测试样本选择方法研究》**。

选择“方法研究”而不是“系统的设计与实现”，因为最终要回答的是选样策略在什么条件下有效，而不是软件功能是否齐全。论文可以同时有算法和原型，但评价重点转为问题定义、已有方法比较、对照与消融、成本测量、失败案例和复现材料。

不建议现在使用“高效”“可靠保证”“最优”“显著提升”等结果导向词。没有实验前不能把预期收益写进标题。若后续只有有限或负面结果，可用更保守的《文本分类模型更新中的回归测试样本选择方法比较研究》；这应由结果和导师要求决定，不能以改名掩盖未做的实验。

## 2. 主问题为什么成立

模型总体准确率提高，不代表所有原有正确预测都保留。负向翻转指同一文本原版本正确、更新版本错误；这一现象和指标并非本项目提出。[ACL 2021 原论文](https://aclanthology.org/2021.acl-long.515/)

定位局部更新变化已有 Model ChangeLists，方向性测试排序已有 GBV-PD，历史模型选取小评测集已有 tinyBenchmarks。因此，本论文不能将“比较新旧模型”“找群体”“未来版本”“加入多样性”单独作为首创点。[ChangeLists](https://doi.org/10.1145/3630106.3659047)、[GBV-PD](https://doi.org/10.1145/3832783.3834368)、[tinyBenchmarks](https://arxiv.org/abs/2402.14992)

本项目提出的**待验证假设**是：在只有少量历史版本、并且无法在选样前取得下一版本全池预测或梯度时，历史问题在可解释群体层面可能比在单条样本层面更容易迁移；对群体进行有饱和性的覆盖，再保留部分文本代表性，可能改善有限预算下的未来负向翻转检出。它可能失败：历史问题可能已修复、更新方向可能改变、特征可能没有表达真实错误模式。

研究对象固定为带公开标签的单标签文本分类，主任务为 MASSIVE 意图分类。主成本问题是**已有完整历史时的一次未见相邻更新**，不是已解决不补全历史的无限滚动监测。槽位识别、开放问答、Agent、视觉、自动修模型和自动批准发布不进入本轮核心范围。

## 3. 一个核心贡献，两个支撑环节

**核心拟贡献：**给出并评价一个历史群体风险驱动的有限预算选样策略 HGC。贡献需要表现为相对强基线的有效性，或在预设误差容限内具有成本、访问要求或可解释性的清楚优势。尚未得到这些证据。

支撑环节一是成对历史行为建模。比较现有群体发现方法与简单枚举，获得特征群体和风险统计；它不被预先包装成第二个全新算法。支撑环节二是一个时间顺序明确、能够阻止目标版本泄漏的实验协议与开放实现。协议和开源本身有复现价值，但不能自动等同于方法创新。

如果群体发现后来在明确目标上呈现独立、稳健的增益，再与导师讨论是否升级为第二项贡献。当前不同时承担两个新算法的证明责任。

## 4. 三个研究问题

**RQ1：在相同样本预算、相同候选池、相同历史信息下，群体感知选样能否比随机、类别分层、历史失败优先、参考版本不确定性和代表性选样检出更多下一版负向翻转？** 主指标是预先指定预算下的 Recall@B，不是已知历史错误的覆盖率。

**RQ2：收益是否来自群体信息和覆盖机制，而不是偶然挑中持续错误？** 比较去群体、去历史权重、去代表性、最近历史与多次历史、不同群体发现器；单列从未出现历史负向翻转的新错误，以及历史错误修复后再次出现的错误。

**RQ3：收益在何种更新类型、历史数量和成本条件下成立？** 改变更新强度、历史数量、预算、文本特征表示；统计建库、每次选样、目标推理的总成本。报告失败条件，不将某个模型的成功概括为所有大模型的结论。

## 5. 明确与最近工作的差异和重合

| 工作 | 已有能力 | 与本研究的关系 |
|---|---|---|
| ChangeLists / AutoSlicer | 比较旧新版在数据子集上的指标差异 | 是群体分析的直接先例；“成对诊断”不是新点 |
| GBV-PD | 读取旧梯度和新旧参数差，不运行目标版本全池推理即可排序 | 是最强的相邻推理预算方法；需单列白盒比较与预处理费用 |
| RiskBlend / MetaSel | 利用新旧模型行为，融合风险或学习错误预测器 | 需要核对目标版本推理和验证标签预算；不可悄悄占用全池目标预测 |
| CASPER | 以变化感知方式对 LLM 系统群体排序，并探测代表实例 | 与“群体＋有限预算”很近；需比较目标探测和复杂系统依赖，不能遗漏 |
| tinyBenchmarks / DeepReduce / AnchorPoints | 用历史模型或参考模型选小集，在其他模型或修改版上评估 | 跨版本选样也已有研究；其聚合准确率目标与负向翻转检出不同 |

各方法的来源、访问条件及核实层级见文献表。**信息条件不同是研究限定条件，不是“因此我们已经创新”的证明。**

## 6. 论文结构与重心

建议章节：绪论；相关工作与问题定义；历史群体风险与样本选择方法；实验设置与复现协议；结果、消融及成本分析；原型与案例；局限及结论。

研究方法与实验结果应占正文主体。原型章节说明如何输入、冻结、执行和审查证据即可；不再用大量数据库表、登录页面、权限和部署配置填充主贡献。篇幅比例只是写作建议，不是学院格式规定。

最终结论的合法形式包括：某类更新下有稳定增益；总体接近但成本更低；只在特定历史条件下有效；或强简单基线已足够。本轮没有真实对比结果，不能先写其中任何一种。
