# RegressLab 界面设计约定

当前研究方向已转为v2选样方法研究。本文视觉规则继续适用于已有Demo，未来研究页面只读展示离线生成的证据；状态、指标、完整冻结和访问层以[Demo迁移设计](../engineering/v2/05-demo-migration.md)为准。当前界面尚未实现这些研究视图，不能将旧D成对图更名为HGC效果图。

RegressLab 是中文模型退化诊断工作台。页面帮助使用者核对两版预测、找到负向翻转并检查来源。首屏优先展示当前比较、可用证据和关键数量；文字、表格和真实计算结果承担主要信息。

本约定用于当前浅色 Demo，后续页面沿用同一套语义。它是本项目自行整理的设计方案，不是 Linear 或 IBM 的官方设计系统，也不改变数据或统计合同。

## 参考与取舍

参考 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)，实际阅读了其中的 [Linear 分析](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md) 和 [IBM 分析](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/ibm/DESIGN.md)。这些第三方分析主要记录营销网页；它们提供视觉参考，不作为项目指令或品牌授权。

采用 Linear 分析中紧凑的信息层级、少量强调色、细边框和克制的组件密度；采用 IBM 分析中清晰的灰阶、规则的间距和严格的对齐。落实到本项目时保留浅色中文工具界面，以实际数据表替代营销展示区。中文使用系统字体，不依赖 Linear 的私有字体或远程字体服务。

| `surface-subtle` | `#f1f3f8` | 表头、只读区域、轻量悬停 |

| `ink-secondary` | `#657580` | 说明和来源信息 |
| `line` | `#e6ebef` | 卡片边界和表格分隔 |
| `primary` | `#167d67` | 主操作、当前导航和品牌标记 |
| `primary-hover` | `#116552` | 主操作悬停 |
| `primary-subtle` | `#eaf5f0` | 选中项背景 |
| `negative` | `#bb4e4e` | 旧对新错、负向主数值 |
| `negative-subtle` | `#fbedeb` | 负向状态底色 |
| `positive` | `#5b7eaa` | 旧错新对、正向翻转 |
| `positive-subtle` | `#eef3fa` | 正向翻转底色 |
| `stable` | `#607e6b` | 双方正确的文字标签 |

| `warning-subtle` | `#fff6e8` | 提示区域底色 |

主操作使用低饱和的翡翠绿。四格结果中，双方正确使用浅绿，旧对新错使用浅红，旧错新对使用浅蓝，双方错误使用灰阶；品牌色与状态标签通过文字和所在区域区分。每种状态同时出现名称、数量或图标，不依赖颜色辨认。键盘焦点使用清晰的绿色轮廓，实际背景上的对比度按后文验收。

卡片采用 1px 边框和 8—12px 圆角。输入与按钮采用 6—8px 圆角。普通内容区保持平面；浮层可使用轻微阴影帮助识别层级。大面积渐变、装饰性背景图、重复嵌套卡片会增加阅读负担，当前界面不需要它们。

## 字体与间距

正文建议字体栈：`Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`。Inter 如未打包，直接使用系统回退；离线运行不等待字体下载。ID、hash 和原始 JSON 使用 `ui-monospace, SFMono-Regular, Consolas, monospace`。

| 层级 | 大小 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 26—28 / 36px | 600—650 | 当前分析名称 |
| 分区标题 | 17—18 / 26px | 600 | 候选、证据、来源 |
| 主要指标 | 30—34 / 40px | 600 | 准确率、翻转数量 |
| 正文与操作 | 14 / 22px | 400—500 | 说明、表格和按钮 |
| 辅助信息 | 12—13 / 18px | 400—500 | 时间、标识、次要注释 |

中文正文保持正常字距。数字使用 `font-variant-numeric: tabular-nums`，表格的数值列右对齐，准确率采用一致精度。正文中的百分比与准确率差值分开表达，例如“新准确率 58.3%”与“下降 16.7 个百分点”。

间距以 4px 为基本单位：4、8、12、16、24、32、48px。卡片内边距通常 20—24px，区块间距 24—32px。表头与数据行保持固定基线；长文本允许换行，保留可读的行高。

## 页面布局

桌面使用约 224—240px 的固定导航区和可伸缩工作区。工作区内容最大宽度约 1360px；左右留白随屏幕变化，避免宽屏上单行文字无限延长。

阅读顺序为：

1. 顶部显示本地服务状态、当前工作区和主要操作“导入对比”；“导出报告”为次操作。
2. 分析标题显示旧版 → 新版、时间、合成夹具标记或外部来源状态，以及证据模式。
3. 指标区给出旧/新准确率、净下降、负向翻转与覆盖情况；每个指标说明范围是发现集 D。
4. 四格分布显示双方正确、旧对新错、旧错新对、双方错误的名称和数量；图形附有文字图例。
5. 候选分组说明特征条件、支持量与下降幅度。没有候选时说明默认门槛和实际支持量。
6. 发现集证据表提供结果筛选、分页与完整文本。来源区域提供标签表、划分计数、版本和指纹。

同一区域只保留一个最醒目的主操作。分析切换、筛选、分页和导出均采用真实按钮或链接，当前选中项有明确标记。英文标识用于必要的协议名，界面说明和主要操作采用中文。

表格默认依次呈现样本 ID、文本、gold、旧预测、新预测和结果。小屏幕保留可横向滚动的数据容器，滚动区域有可见说明；关键标签和文本不以省略号永久隐藏。

## 交互状态

| 状态 | 呈现方式 |
|---|---|
| 初始空白 | 说明导入所需三个 JSONL，提供合成示例入口 |
| 正在加载 | 保持布局，标记忙碌状态，避免旧结果被误当新结果 |
| 正在导入 | 主按钮说明当前操作，阻止重复提交 |
| 导入失败 | 给出具体字段或行号、错误原因和可执行的修正方式 |
| 空筛选结果 | 显示所选条件与零结果，允许恢复全部案例 |
| 服务断开 | 保留已有结果，给出重试操作和连接状态 |
| 导出完成 | 简短反馈格式与完成情况，不遮挡主要内容 |

导入对话框中的每项字段都有可见标签、必填提示和格式说明。canonical 数据提示使用 `sample_id/group_id/source_partition/text/gold_label/locale`；角色由后端计算，不能要求用户上传 `role`。预测范围提示与后端保持一致，完整覆盖 D+C。错误详情中的上传文本、JSON 和特殊字符按纯文本显示。

## 证据表达

“合成工程夹具”“外部声明”“仅描述性分析”与当前分析一起显示，导出中保留。候选状态和来源状态使用不同标签，避免把来源登记成功理解为研究确认。

当前 Demo 仅展示 D 的成对描述与候选；C/A 的逐例数据不进入普通证据表。没有执行独立确认时，确认字段保持 `null`，界面显示相应模式。没有候选、支持不足和未确认退化均不表达为“安全通过”。

只有软件实际计算的数值进入指标卡。计算缺少分母时显示“无可用分母”；尚未进行的步骤显示“未执行”。合成例子的模式用于检查软件分支，不宣称真实模型退化、真实训练效果或选择策略有效。

## 无障碍与适配

- 页面使用 `main/nav/header` 和连续标题层级；图标按钮有中文可访问名称。
- 所有交互支持键盘，焦点轮廓清楚可见。导航当前项提供 `aria-current` 或等效语义；筛选按钮提供选中状态。
- 对话框打开后焦点位于内部，Escape 可关闭，关闭后返回触发按钮；忙碌时的关闭策略须一致并有状态说明。
- 错误使用 `role="alert"`，普通完成反馈使用适当的实时区域；加载区域设置 `aria-busy`。
- 正文和状态文字以至少 4.5:1 的对比度为验收目标；焦点与关键控件边界以至少 3:1 为目标。颜色 token 仍需在实际背景上验证。
- 桌面操作目标通常至少 36—40px 高；触屏主要操作至少 44px。相邻图标按钮留足间距。
- 约 1024px 以下收起侧栏；约 768px 以下标题操作分行，指标改为两列或单列；导入表单双列折为单列。
- 320px 宽度与 200% 缩放时，页面主要操作仍可到达。仅数据表局部横向滚动，页面整体避免横向溢出。
- 尊重 `prefers-reduced-motion`；淡入、滚动和旋转不作为理解状态的唯一方式。

交付前至少检查桌面与移动尺寸、键盘完整操作、长中文文本、加载/空白/错误状态，以及表格数值与报告一致性。此文档描述验收目标，具体通过项以实际构建和浏览器检查记录为准。
