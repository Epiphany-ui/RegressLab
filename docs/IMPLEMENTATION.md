# 当前实现与后续里程碑

## 已理解并保留的产品目标

系统维护有公开gold的固定标签文本分类应用，比较更新前后版本，识别旧对新错，在D发现可解释分组，以合格稳定性与来源证据的一次C确认后精选冻结套件，对未来版本真实重放。主实验使用TRAIN-only小语言模型LoRA检查点链，逻辑回归重训为传统对照。模型更新、推理配置变化和来源声明必须分别记录；合成夹具不属于研究证据。

数据流和科学边界来自 PRODUCT、02—04、11、17、19；应用/持久任务来自05—10、12—14。已保留全部机器合同与教师Word。原始文档仍为完整成品的设计基线，其中“未实现”的历史文字对应2026-10-22设计阶段；当前软件进展以本文件和验证记录为准。

## 有意缩小的架构

为让本地Demo不依赖未配置的数据库/GPU，使用SQLite和有界同步计算。独立 `/api/demo` 明示此差异。没有用内存队列冒充持久Worker，没有使用 BackgroundTasks 承担恢复任务，也没有把Demo身份当正式ModelVersion身份。5000行/10MiB是本阶段容量护栏。

所有输入按实际字节限制，文件名不参与路径；未知字段、重复JSON键、NaN/Infinity、BOM和不完整预测拒绝。归一化同文本/同group构造传递组件，跨官方分区失败。D-only计算与C/A原文隐藏经过软件测试；数据库拥有者仍能读取私有输入，不能把此边界描述为抵抗本机管理员的安全隔离。

成功数据不可更新，只新建分析。历史有SQLite事务和checksum，但没有实现最终产物卷、attempt_token租约、取消或崩溃恢复协议。失败上传只保留摘要/错误码，是相对P0受限原始工件留存要求的未完成项。
