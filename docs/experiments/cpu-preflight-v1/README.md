## 隔离审计与正式资格

发现同种子A.f3与B.f2的模型pickle SHA完全相同，预测也一致，共3对，明细见audit/verification。两个家族的训练基座和C=1全TRAIN配方相同，链名不同并未产生独立节点。

每条选择器的实际输入仅有自己的f0—f2，且事件显示所有显式f3 DEV调用在全矩阵冻结后；但A的目标模型已经以B的历史模型形式出现，因此**不能声称全局目标行为在冻结前均不可见**。本轮所有结果保留为开发探索，`formal_blind_evaluation_eligible=false`。日志与文件hash记录实际实现路径，并非对抗式操作系统权限隔离。

下一轮在登记前比对全矩阵目标与任何历史节点的语义模型身份，包括训练ID、词表/IDF、类别坐标、系数和截距。仅改文件名或pickle字节不算消除等价；只有配置/语义身份审计通过才进入保留目标评价。不得重跑覆盖这批发现或把改配方后的结果补成同一次登记。

## 资源与成本边界

全流程墙钟127.60秒，峰值RSS 611,420KiB（约597.1MiB）；含24次CPU训练、选样、冻结和DEV评价，不含此前下载与依赖安装。Python 3.14.4、NumPy 2.5.4、SciPy 1.18.1、scikit-learn 1.9.1，Linux/WSL2；完整锁文件纳入Git。

单次fit约3.55—6.87秒；每链整批9基线/全部预算种子选择约0.64—0.73秒；完整DEV_SELECTOR的目标评分阶段约0.0018—0.0028秒。后者包含predict_proba与一致性检查的predict，不含文本transform；前者是整批选择，不能直接用二者推断单一方法的节约或亏损。当前CPU任务推理便宜，尚未证明净节约；需要每方法、相同范围、含预处理/共享建库/摊销的成本账。

实际`nvidia-smi`探测为NVIDIA GeForce RTX 3060 Laptop GPU、6144MiB；未进行GPU训练、LoRA或显存实测，不能沿用桌面3060的显存假设。配置中的180秒/模型是fit返回后的检查，尚非进程硬超时。

## 阶段判断与下一轮

登记的机械规则“每家族至少2条链出现≥1个翻转”已满足（均为3/3）；它只回答是否存在开发信号，不代表正式G1通过。CPU训练可行性已实测，G0的神经资源等其余部分仍未完成。

1. 先写下一轮开发登记：消除跨链目标/历史等价，明确独立链单位和全局访问边界，保留首轮所有结果。
2. 先做模型无关的DEV类别/组件支持与独立外部数据可用性审计；按预登记规则报告稀疏/零翻转，不根据已看目标反复挑seed或调配方。
3. 补每方法可比成本、强margin参照及机制可评价性检查，明确最低有效事件量/可测出口。
4. 完成这些开发复核后，再决定进入HGC最小实现和四类机制试验；GPU资源预实验另设预算，正式TEST继续保留。
