# 历史信号对margin的增量检验：事前协议

**本阶段是固定的小规模增量价值检验，不是论文正式TEST或HGC续调。** 2026-10-24用户明确要求先检验历史信息是否补充margin，再决定具体题目和方法。本协议与[机器配置](../../../experiments/configs/history-increment-v1.json)共同在新留出链目标解封前提交；实际执行commit、源码/锁文件hash、配置与时间由运行登记记录。核对结果必须按下述门槛报告，不能事后更换。

## 2. 配对的margin与历史增量检验

使用相同的StandardScaler＋L2逻辑回归，比较两套输入：

| 输入 | 固定列 |
|---|---|
| margin-LR | f2的top1减top2概率间隔 |
| margin-history-LR | 同一margin，加历史错率、历史负向翻转率、最大gold概率下降、历史概率分布变动、冻结群体风险共5列 |

历史错率是f0/f1预测错误比例；负向翻转率以f0→f1及f1→f2的旧正确机会数为分母，无机会记0；gold概率下降取两个相邻历史转移的最大正向下降量；分布变动取两个相邻转移的总变差距离均值；群体风险是原固定m30/k3/λ0.5合同中群体normalized weight之和，不使用HGC选样目标。后者的k/λ不参与群体风险计算，完整旧配置保留以维持来源合同。

特征接口只接gold、f0—f2预测与概率，不接f3。P内最近f1→f2负向翻转恒零，这一事实写入测试，不能将它伪装成有效新信号。训练标签仅是已曝光开发链的f2正确而f3错误；新留出标签只在套件冻结后供计分。Risk-LR是已有方案的检验工具，不包装为新算法。

两模型共用C候选`0.01/0.1/1/10`、lbfgs、最多1000迭代、tol=1e−8，同一标准化及权重规则。每架构分别做四折leave-one-entire-chain-out，以有效验证链的宏平均AP选C，差≤1e−12取较小C；每折Scaler及LR只拟合其他三链。每链权重质量相同，并在各自观测到的类别间均分，之后全局归一为平均权重1。这是类别平衡的诊断分数，不是按自然事件率校准的概率。

无正例/负例的验证折明确NA、两方法同步排除；不足两个有效折则停止该增量检验，不向新目标借标签。最终以该架构全部四开发链重拟合并冻结。原始低margin排序另作强锚点；仅胜过margin-LR而不改善原始margin，不能视为获得实用补充。

## 3. 固定模型与两种更新条件

| 条件 | 四版TRAIN变化 | 能回答的问题 |
|---|---|---|
| growth | 按label固定seed的嵌套40%/60%/80%/100% | 数据增长更新下的历史补充 |
| refresh | 每label固定seed排序后分5个近等大block，f0/f1/f2/f3各排除block0/1/2/3，使用其余约80% | 训练数据轮换下的历史补充 |

refresh是相同闭集TRAIN内的真实数据更替，不注入错误标签，也不按已见结果挑选退化样本。150类中部分清理后计数为99，因此“80%”允许每类至多一条的取整差异。两架构同seed和family必须使用完全相同的训练ID。

SGD沿用固定log-loss/L2、alpha=1e−4、20epoch的既有参数，TF-IDF字符2—4gram、max30,000。神经模型为词嵌入64维、平均池化、64维ReLU隐层及150类输出，dropout=0，Adam lr=0.003、batch128、固定12epoch，词表上限12,000、max length40。它是实际训练的非线性小网络，不称为预训练Transformer、LLM或LoRA证据。各版从头训练，并保留实际TRAIN ID、权重hash和保存恢复核对；固定epoch完成不等于已证明优化收敛。

每chain的TF-IDF词表/IDF或神经词表在该seed固定40% TRAIN基底拟合，四版共用，不含VAL/TEST。refresh某版的实际80%训练集未必包含整个基底；固定表示允许接触这些仅属于TRAIN的无监督文本，必须与“每版只见自身训练子集的文本”区分。

资源先行：只用不超过2,000条TRAIN、2epoch进行神经probe，CPU Torch固定2线程，不读取DEV/TEST模型结果。记录训练/预测时间、模型参数量、RSS、版本与设备，按机器配置的耗时/内存门决定是否执行神经链；不通过则保留失败与不足结果，不在DEV上调配方。有限神经开发与留出共16＋24次训练，不扩展到大型LoRA。

## 4. 全矩阵冻结与一次目标评价

执行顺序固定：源码/config登记 → TRAIN-only资源关 → 数据审计 → 完成全部64次新训练及全局身份门 → 仅开发神经链目标曝光 → 各架构整链开发定参 → 仅预测新留出f0—f2 → 全部12链套件冻结 → 单次解封新f3计分。开发链VAL目标曝光是许可的，留出链f3的VAL预测必须在所有套件冻结后才出现，不能逐链看到结果后改后续配置。训练时允许各slot（含f3）在最多32条TRAIN样本上核对保存恢复，事件明确标记TRAIN_ONLY；这类模型自检不接触留出VAL或TEST。

目标身份与全部新历史/其他新目标及此前模型状态比较，排除登记范围内的复用。hash身份不是模型函数不等价的完备证明，也不赋予统计独立性。预测器、特征、P、排序、全体模型、开发来源和套件文件纳入冻结；hash事件链、矩阵完整性及事后重算应通过复核。

P为f2预测正确的完整VAL集合，未来事件R为P内f3预测错误。固定预算20/50/100/200，主预算100；相同链的所有方法共P和B，固定排序取前缀，同分按sample_id UTF-8字节序。空P、R=0、低事件、资源/身份失败与未执行项都保留，不仅汇报有利链。

## 5. 指标、门槛与明确出口

主比较是B100的history-LR减margin-LR配对Recall，并同时核对原始margin。报告完整预算曲线、AP/AUROC、实际检出与漏检、新错/修复后复发及成本。AP/AUROC提高不自动等于同预算检出改善。

**每个架构×更新条件**有3条链；该格支持充分要求全部R≥20。稳定增量筛查要求同时满足：

- B100平均Recall提升≥0.05，且至少2/3链提升严格为正；
- 任一链Recall损失不低于−0.05；
- 平均AP提升严格为正；
- 相对原始margin的平均B100 Recall提升严格大于0。

大于等于的边界仅允许1e−12浮点容差，AP和相对原始margin的正增益仍为严格大于0。这些是务实的描述性门槛，不是正式显著性、功效或非劣界限。按链再按预先指定的架构/条件汇总，不能把文本行、选样seed、多个预算或重复计时当作独立更新。3个同数据训练实现不足以支持普遍优越性；不靠少量chain bootstrap制造强统计主张。

| 出口 | 固定解释与动作 |
|---|---|
| 同一更新条件在两架构都通过 | `REPLICATED_INCREMENT_CANDIDATE`：支持为该条件另设正式研究；尚未确定题目、方法创新或总体优势 |
| 仅某架构/条件通过 | `CONDITIONAL_SIGNAL_REQUIRES_REPLICATION`：保留具体线索，明确未跨架构复现，不当作GO或自动加跑 |
| 四格支持均充分但均未通过 | `NO_DETECTED_STABLE_INCREMENT`：本配置下未检出稳定补充，停止追逐历史风险新算法 |
| 无稳定通过且有格事件不足 | `INCONCLUSIVE_EVENT_SUPPORT`：证据不足，停止自动扩大；不是统计零效应证明 |

资源/身份/冻结失败另行保留为受阻记录，不越过门继续计分。两个负向出口都不自动追加seed、改特征或继续参数搜索。若需要新证据，先具体说明当前缺口，另设独立登记。新目标解封后的历史子群分析只能描述，不能重定义本轮分组和通过标准。
