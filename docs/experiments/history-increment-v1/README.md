两个预测器均采用相同Scaler＋L2 LR及四候选C，仅输入列不同。SGD用此前已曝光的CLINC四链，事件数22/16/1/3；神经新开发四链事件数53/65/95/89。开发整链LOCO选出的C：SGD为margin0.01／增强10，神经为两者均0.01，见[定参全记录](run/development-tuning.json)。新留出目标没有进入拟合、标准化或C选择，单个稀疏开发链的高权重影响仍是限制。

TRAIN-only资源试验先通过，再执行真实链：1,495条TRAIN、2epoch、CPU2线程，训练1.335秒，32条TRAIN推理1.873毫秒，进程峰值RSS756.85MiB，恢复精确；DEV/TEST模型输入0。资源门与主运行是不同进程，不能把两个峰值作同一模型的控制比较。神经正式模型为64维词嵌入＋平均池化＋64维ReLU MLP，约22.73—22.79万参数，12epoch；f2的VAL准确率83.62%—85.15%。这是真实的小型非线性训练，未做GPU、预训练Transformer或LoRA实验。资源[登记](resource/registration.json)和[结果](resource/report.json)均保留。

## 成本没有建立优势

缓存历史不等于历史免费。按本次固定CPU流程，SGD历史推理约397—412毫秒／链，小神经约122—165毫秒／链；共用特征构造分别约113—120毫秒和131—155毫秒，之后全部预算/方法的选样另约8—9毫秒。直接全P目标推理分别约115—124毫秒和26—27毫秒。

因此当前特征流程没有建立端到端部署成本优势；神经特征构造本身已比直接全P推理慢。本阶段支持的是信息增量线索，不能把它等同为已可部署的高效选样方法。拟合、训练、全池历史缓存、重复评测和复核成本另计。目标暖缓存3次中位数含文本规范化/编码/模型概率推理，不含选样；细项见[历史成本](run/history-costs.json)与[目标成本](run/target-costs.json)，不从子集／全P推理比率宣称总节省。

## 解释边界

每格3个seed来自同一数据集与共享VAL，只有描述性筛查意义。SGD开发链是增长/epoch变化，而神经开发包含增长/refresh；SGD的refresh还包含对未见更新条件的迁移。小网络从头训练，不能外推到预训练Transformer、LLM或LoRA。链内类别平衡的Risk-LR输出是诊断分数，Brier仅描述这些分数与事件的平方误差，不把它当自然事件率校准证明。AP提高也不能替代同预算检出提升。

本阶段依据固定出口决定是否还有具体线索；即使有正结果，也不自动确定最终题目、创新性或论文正式结论。没有稳定增量或事件不足时，停止自动追逐历史新算法，不在本轮新曝光目标上再搜索特征和参数。
