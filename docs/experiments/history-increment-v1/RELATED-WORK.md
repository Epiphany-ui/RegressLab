# 增量检验的相邻工作与贡献边界

核验日期：2026-10-24。以下依据作者论文、arXiv正文和正式会议页面；这是与本阶段直接相关的核对，不是完整文献综述，也没有复现这些工作的实验。

## 1. 最接近的2026信号比较

Sheng与Lu的[No Universal Signal Predicts Sample-Level LLM Regression under Version Updates，arXiv:2608.13607v1](https://arxiv.org/abs/2608.13607v1)于2026-08-11提交，当前所核验页面为预印本。它比较LLM更新时的不确定性与跨版本行为信号，并发现有效性依赖任务和更新。**“不同信号在不同任务上有效”不能成为本项目独有的发现。**

更直接的重叠在[正文3.3节与4.1节](https://arxiv.org/html/2608.13607v1)：作者以相同逻辑回归比较基础信号和加入其他信号后的增益，用分层五折评价AUROC。其主对照是新模型confidence，跨版本信号需要新旧模型在同一输入上的输出；这与本项目在f3执行前只用f0—f2历史的访问边界不同。本文据此区分研究问题，不能把Risk-LR或“基础＋增强”检验本身说成新算法。

本阶段具体问题是：**固定更新机制与候选池后，历史信号能否在整条未见更新上，补充当前参考版本margin？** 研究单元是完整更新实现，报告同预算检出和信号增益。新链仍使用已曝光的VAL样本，不能称为同时留出样本与模型的最终泛化检验；这里的访问和留出差别也不是已经成立的学术创新。

## 2. 定向更新参考

Cho、Shin与Ko的[Evolution-Aware Regression Test Prioritization of ML-Enabled Systems Using Gradient-Based Behavior Vectors，arXiv:2606.28037v2](https://arxiv.org/abs/2606.28037v2)采用参考模型损失梯度与实际参数更新方向，排序时不运行目标模型。原始页面记载ASE 2026接收及正式DOI，不能将它笼统称为未经审议的预印本。它要求可对齐参数、可微损失和目标权重；本阶段纯历史工具不使用目标参数差。这是不同信息条件，不能据此免除未来论文中与强参考比较的责任。

## 3. 历史行为、小评价集与训练动态

[Anchor Points: Benchmarking Models with Much Fewer Examples，EACL 2024](https://aclanthology.org/2024.eacl-long.95/)利用跨模型行为相关性构造少量评价点，主要目标是模型排名和整体预测估计。因此，历史预测矩阵、少量套件和跨模型迁移本身都有先例；本项目的定预算负向翻转检出与其目标不同，不能把目标差别直接当成优越性证明。

[Dataset Cartography: Mapping and Diagnosing Datasets with Training Dynamics，EMNLP 2020](https://aclanthology.org/2020.emnlp-main.746/)用训练过程中的gold置信度及其变动刻画样本。历史置信度波动具有既有研究背景；不同checkpoint、独立重训更新与真实发布版本并非相同实验单元，不能直接把训练动态结论迁移过来。

## 4. 这一阶段能支持的具体发现

可以检验的候选发现包括：在同一闭集意图任务和数据增长配方中，历史个体翻转、gold置信度轨迹或预先固定的群体风险，是否改善margin已提供的排序；增益是否在新训练实现中重复；各架构分别用自己的开发链拟合后，在小神经模型中是否也有补充。神经与线性信号差异只能是架构条件下的初步描述，不宜从一个数据集、一个更新家族推出原因。

如果只看到历史风险单独优于Random、某个链出现新增错误、或者合并两套B题后检出增加，都不能回答同预算的增量价值。若增强模型只超过拟合失败的margin-LR，却低于原始margin排序，应判为尚未获得实用补充。

如果未见链没有稳定增益，结论应限定为已登记的信号、预测器、数据和更新条件。不得写成“所有历史信息无价值”，也不继续在本轮目标上追加特征以寻找赢家。若观察到增益，也只足以决定是否值得另设正式研究，不能自动确立创新性、最终题名或论文完成。
