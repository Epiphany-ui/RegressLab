# 文档验证记录

本文保留2026年10月22日1.3设计阶段的审阅及未执行项，不是当前Demo产品验收。当前应用结果见[应用验证记录](../quality/VALIDATION.md)。设计静态检查输出见[static-checks.json](static-checks.json)及[revision-checks.json](revision-checks.json)。

## 审阅与修订

本轮分别审查实验/统计、数据与接口合同、教师材料，并由一名未参与编写的评审者对PRODUCT、版本生成协议、需求、测试、计划及实验规程进行初审。初审提出两项跨合同缺口：A/完整候选池预测没有明确lab入口，以及来源/登记方式可能改变模型身份并绕过一次C限制。

已新增独立LAB_ONLY预测manifest及受审计CLI，HTTP仍不开放A；应用身份只使用标签/权重/推理设置，数据确认键使用evaluation_data_sha256，来源元数据、kind和新UUID不能重置。后续完整合同修订由主审做静态交叉核对，未冒称另一次独立全合同批准。

其他修正包括：真实LoRA检查点和LR重新训练来源、同run检查点相关性、未来预测冻结、DEV100例×3稳定性资格、描述降级不读C、原始响应与解析标签一致、完整覆盖与单run、数据冲突预处理留痕、浮点分数改直接元组比较、零分母NA、完整实验成本及6GB未测边界。

## 可重复静态检查

在仓库根目录执行`node scripts/check-design.cjs`，脚本按自身位置定位输入并重写`docs/verification/static-checks.json`。17组检查覆盖JSON解析/本地引用、OpenAPI路径与幂等、有效和非法样例、成对四格与精确小样本尾概率、Holm与选择算例、五基线/消融、DDL静态引用、链接、版本/运行/证据合同、条件Schema、本地权重缺失拒绝、lab隔离、微小多样性排序和需求/来源追踪。

当前合同为43个HTTP操作、37条路径、61个组件Schema、17张表。自带校验器覆盖本包使用的关键形状和allOf/if/then条件，**不是完整标准认证的JSON Schema/OpenAPI验证器**；DDL未在PostgreSQL执行。默认统计/精选参数未晋级，未声称算法效果已验证。

教师两页Word经云端转换逐页视觉检查；本地标准渲染器因缺少捆绑LibreOffice无法运行，未调用用户桌面LibreOffice。转换后的PDF没有成功下载成本地文件，故本包只交付Word，不伪造PDF或沿用旧版。独立输出Word和包内Word内容相同。
